# Sicherheit

Bitte keine Sicherheitslücken als öffentliches GitHub-Issue einstellen.

Melde sie per E-Mail an **niklas@terhorst.io** mit:

- betroffenem Addon und ungefährer WHMCS-Version
- kurzer Beschreibung und, wenn möglich, Schritten zur Reproduktion
- erwartetem und tatsächlichem Verhalten

Bestätigte Probleme werden nach dem Fix in einem Release erwähnt.
