# WHMCS Addons

Kostenlose [WHMCS](https://www.whmcs.com/)-Module, die ich selbst nutze und hier zur freien Verwendung bereitstelle.

Jedes Addon liegt im üblichen WHMCS-Pfad (`modules/…`). Den jeweiligen Ordner nach `WHMCS_ROOT/modules/…` kopieren, im Admin aktivieren und konfigurieren. Details stehen in der README des Addons.
